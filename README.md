# Cybersecurity Learning Notes

Practical beginner-friendly notes for Linux, command-line tools, and cybersecurity basics.

## Folders

- `linux-cheatsheets/` — concise command references, added one topic at a time.
- `python-scripts/` — reserved for small, documented scripts that add something distinct from the existing [My-CyberSec-Journey tools](https://github.com/phsecx/My-CyberSec-Journey); this starter contains no Python code.
- `thm-writeups/` — reserved for permitted study notes; no room-specific writeups are included in this starter.

## Safe use

- Check the target path before running commands that change or remove files.
- Use Nmap only on localhost, systems you own, or targets you have explicit authorization to test. Check applicable rules and laws.
- Do not publish credentials, private data, TryHackMe flags, or answers. Add room-specific notes only after completing the room and checking its sharing rules.

These are concise study references, not exhaustive manuals. Check your system's `man` pages and the linked official documentation because command options can vary by platform or version.
